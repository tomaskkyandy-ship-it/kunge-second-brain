| 悲观 | ___% | −___% | | |
| **合计** | 100% | | | **EV = ___%** |

> [!tip] 计算方式
> EV = 乐观概率 × 乐观回报 + 基本概率 × 基本回报 + 悲观概率 × 悲观回报
> **EV 必须显著高于「无风险利率 + 风险溢价」（通常 10%+）才值得下注。**
