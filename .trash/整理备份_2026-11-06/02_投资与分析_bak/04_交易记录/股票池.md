## 📋 使用时填哪些属性

| 属性 | 填什么 | 示例 |
| :--- | :--- | :--- |
| `ticker` | 股票代码 | `600519.SH` |
| `company` | 公司名称 | `贵州茅台` |
| `sector` | 行业 | `白酒` |
| `status` | 观察中 / 研究中 / 已建仓 / 已放弃 | `研究中` |
| `price` | 当前股价 | `1680` |
| `score_rate` | 30 维度得分率（%） | `78` |
| `traps_hit` | 17 项陷阱命中数 | `0` |
| `position_pct` | 目标仓位（%） | `8` |
| `verdict` | 一句话结论 | `质量优秀但估值偏高，等待回调` |

> [!tip] 视图不会自动更新属性
> 打分完成后需要手动把结论填回 YAML，否则视图里对应列会是空的。
> 个股笔记和交易记录共用一个文件夹，靠 `action` 属性区分：**个股分析不填 `action`，交易记录必须填**。
