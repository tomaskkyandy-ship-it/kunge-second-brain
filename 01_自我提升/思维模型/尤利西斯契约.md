# ⚓ 尤利西斯契约 (Ulysses Contract)

> **核心定义**：用**今天清醒的自己**做出的决定，**物理剥夺**明天疲惫/受诱惑的自己的错误选项。

---

### 🧠 典故与本质

奥德修斯（尤利西斯）在航经海妖塞壬海域前：
- 命船员用蜡封住自己的耳朵
- 把自己牢牢绑在桅杆上
- 下令：**无论我稍后如何苦苦哀求，都绝不松绑**

**本质**：预先限制未来的自己，而不是依赖未来的自己「保持意志力」。

---

### 🧠 生理节律依据

* 人的自制力在**早晨起床时最强**
* 随一天决策消耗，到**晚上 9 点跌至谷底**
* 因此：重要决定在早上做，晚上**根本不给自己做决定的机会**

---

### 🛠️ 实操清单

| 想戒掉 / 想坚持 | 对应的尤利西斯契约 |
| :--- | :--- |
| 睡前刷手机 | 充电器移到客厅；手机定时锁盒 21:00 上锁 |
| 吃垃圾零食 | 家里**绝不存放**（不是「少吃」，是「不存在」） |
| 深夜冲动购物 | 购物 App 卸载；支付密码交给家人 |
| 熬夜改计划 | 21:00 后禁止修改任何计划文件 |
| 冲动交易 | 券商 App 设交易密码；下单前必须手写 EV |
| 无意义刷视频 | 路由器定时断网；浏览器屏蔽站点 |

---

### ⚠️ 两条使用原则

1. **在早晨设置，不要在情绪激动时设置**（否则捆住的是清醒的自己）
2. **必须是物理动作，不能是口头承诺**——「我明天一定不看手机」不是契约，「把手机锁进盒子」才是
