## 🛠️ 卡片使用约定

每张卡片末尾都有 **`## 💼 我的案例`** 区块，这是**唯一由你填写**的部分。

> [!warning] 空卡片 = 没学会
> 22 张卡片目前**全部是「别人的框架」，你的案例区是空的**。
> 建议节奏：**用到哪个填哪个**，不要一次性全填。

### 推荐填写顺序

按你最近的实际需求来，而不是按目录顺序：

1. 如果最近在拖延 → [[意志力涣散]] + [[决心循环]] + [[尤利西斯契约]]
2. 如果最近要做投资决策 → [[期望值 EV]] + [[结果论陷阱]] + [[事前验尸]]
3. 如果最近时间不够用 → [[机会成本]] + [[时薪与外包法则]] + [[幂律法则]]
4. 如果最近被数字/指标困扰 → [[古德哈特定律]] + [[地图与疆域]]
