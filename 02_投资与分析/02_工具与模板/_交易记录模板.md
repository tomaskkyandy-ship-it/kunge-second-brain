# 🧾 交易流水单 · {{公司名}}（{{action}}）

> [!todo] 怎么用（买入建单 vs 卖出建单双轨规则）
> 本模板存放在 `02_投资与分析/04_交易记录/` 下，按以下两种操作场景极简填写：
> 
> 🟢 **买入 / 加仓建单时**：
> 1. 复制本文件，重命名为 `YYYY-MM-DD {{公司名}} {{批次}}买入.md`（如 `2026-11-12 Alphabet GOOGL 第一枪买入.md`）；
> 2. 交易前先对照 [[{{公司名}}]]（存放于 `03_个股研究与股票池/`）核验质量分与击球区；
> 3. **完整填写【📌 交易概要 + 第一、二、三节】**（第四、五节留空，待未来平仓时回填归因）。
> 
> 🔴 **独立减仓 / 卖出建单时**：
> 1. 若单独新建卖出流水单，命名为 `YYYY-MM-DD {{公司名}} {{操作}}.md`（如 `2027-03-01 Alphabet GOOGL 泡沫止盈卖出.md`）；
> 2. **只需保留【📌 交易概要 + 📤 四、卖出与退出记录 + 🔍 五、四象限归因复盘】**，直接删掉中间的第一至三节！
> 3. **关联买入单闭环（防僵尸单）**：在顶部 YAML 填写 `related_buy: "[[买入单文件名]]"`；**建完卖出单后，顺手打开对应买入单，将其 YAML 的 `outcome: 进行中` 改为 `已结清` 或 `部分止盈`**！
> 
> *(注：顶部 YAML 的 `action`、`batch_stage` 必须如实填写，Bases 视图通过 `company` 属性自动关联个股主档案)*

## 🔍 五、四象限归因复盘（对应 [[结果论陷阱]]）

> [!important] 诚实归因：结果好不等于决策对，结果差不等于体系错
> - [ ] **决策对 + 结果好** $\implies$ 应得的实力（Skill），复制该流程
> - [ ] **决策对 + 结果差** $\implies$ 概率与黑天鹅运气，**不要怀疑体系，继续执行纪律**
> - [ ] **决策错 + 结果好** $\implies$ 侥幸与定时炸弹，**必须深刻反思，杜绝下次违纪**
> - [ ] **决策错 + 结果差** $\implies$ 付出的学费，**将错误写入《投资决策日志》与避坑清单**
