## 📐 30 维度打分（详见 [[选股评分模型]]）

> [!warning] 评分标准
> 5 = 极强正向｜4 = 较强正向｜3 = 中性/信息不足｜2 = 较弱负向｜1 = 极强负向（明显不满足）
> **信息不足一律给 3 分**，不要臆测。
>
> **⭐ = 权重 3 关键变量（10 项）**：任何一项 ≤ 2 分，无论总分多少都要重新考虑整笔投资。
> **◦ = 权重 1 辅助项（4 项）**：加减分项，不主导结论。

## 📈 贝叶斯动态更新与复盘记录（详见 [[新闻过滤与贝叶斯动态更新系统]]）

> [!tip] 应对每日新闻的唯一入口
> 1. **半衰期过滤**：<1 周的一级噪音直接划走；只记录半衰期 >1 季度的**二级（周期拐点）**与**三级（基因突变/黑天鹅）**事件。
> 2. **冷却期纪律**：看到大新闻先观察 **24–48 小时盘面证言（该涨不涨 vs 该跌不跌）**，再按证据强度（口头弱证据 vs 财报/法律强证据）调分，跨过阈值才动仓位！

| 日期 | 重大事件 / 财报 / 政策（二级/三级信号） | 影响维度编号 & 证据强度（弱/强） | 先验分 $\to$ 后验分 | 48h 盘面证言（Price-in / 看涨或看跌背离） | 最终决策与归因（决策对/运气/判断错） |
| :--- | :--- | :--- | :---: | :--- | :--- |
| | | | | | |

> [!note] 归因纪律
> - **决策对 + 结果好** = 应得的（skill）
> - **决策对 + 结果差** = 运气不佳，**不要怀疑体系**
> - **决策错 + 结果好** = 定时炸弹，**必须修正**
> - **决策错 + 结果差** = 学费，**记录教训**
