# 📈 股票池（三桶杠铃架构：75%–85% 皇冠复利 × 10%–15% 新物种奇兵 × 5%–10% 战略现金）

> [!info] 组合顶层架构：巴菲特 × 泰尔「三桶物理隔离杠铃策略」
> 页面由 `03_个股研究与股票池/` 下所有活跃标的笔记自动汇总而成，实行严格的**三桶分轨管理**与**「🟢学徒买 + 🔴师傅卖」双扳机监控**：
> 1. **💎 皇冠明珠·复利池（75%–85% 资金上限）**：用 [[选股评分模型]]（30维度）与 [[加密资产评分模型]]（21维度）考核，只选 `质量分% >= 75`（或归属 `💎皇冠明珠复利池`）的顶级现金牛/硬通货，等错杀折价按 3-4-3 扣动买点扳机。
> 2. **🚀 新物种与奇兵高赔率池（10%–15% 资金上限，其中 🪙加密原生代币严格锁死 ≤5%）**：用 [[颠覆性新物种与生命力评估模型]]（15维度第一性原理记分卡）考核，专门捕捉像 [[SpaceX SPCX]] 这样早期因高研发/高 CapEx 导致传统财务表失真、但具备 **10倍成本下降曲线（莱特定律）与极客创始人统治力** 的时代级新物种（`新物种生命力% >= 80`）。
> 3. **💵 战略现金与黄金坑预备队（5%–10% 底线）**：平时收美元短债/货币基金利息，专为黑天鹅暴跌或第三枪（30% 重锤）提供无条件流动性。

## 🚀 二、新物种·颠覆者观察池（新物种生命力 ≥ 80% · 10~15% 奇兵高赔率仓）

> [!tip] 为什么单独设立新物种池？（详见 [[颠覆性新物种与生命力评估模型]] & [[新物种与候选猎物雷达池]]）

| 属性（纯中文） | 填什么 | 示例 |
| :--- | :--- | :--- |
| `标的名称` | 笔记显示名（与文件名一致） | `Alphabet GOOGL` |
| `公司全称` | 公司/资产正式名称 | `Alphabet Inc.` |
| `代码` | 股票/代币代码 | `GOOGL` / `BTC` / `SPCX` |
| `类型` | `股票` 或 `加密资产` | `股票` |
| `所属池子` | `💎皇冠明珠复利池`、`🚀新物种观察池`、`⏳周期观察池`、`🧬0→1研发VC池(≤2%)`、`🪙加密资产配置(≤5%)` | `💎皇冠明珠复利池` |
| `宏观因子篮子` | `🌊流动性久期` / `🔥通胀实物` / `🛡️刚需现金牛`（单篮子 ≤50%） | `🌊流动性久期` |
| `行业` | 行业/赛道 | `互联网 / 云计算 / AI` |
| `状态` | `观察中` / `持仓中` / `放弃`（标为放弃将自动从云端日报隐藏） | `观察中` |
| `现价` | 当前最新价格（由同步脚本自动刷新） | `280.2` |
| `🟢学徒买点` | **🟢 学徒买点**：预设 30% 底仓狙击价或右侧拐点条件 | `$230 或单季FCF转正(+$150亿)` |
| `🔴师傅卖点`| **🔴 师傅卖点**：泡沫止盈价 / 移动护利线 / 逻辑证伪清仓红线 | `$420(PE>35x泡沫止盈) 或 Cloud利润率<20%证伪清仓` |
| `目标仓位%` | **计划目标仓位**（%） | `15` |
| `当前仓位%` | 当前实际持仓占比（%） | `0` |
| `💣排雷日历` | **💣 下次排雷日历**（解禁 / 财报 / 诉讼） | `2026-12-08` |
| `核心KPI` | 季报必盯 3 个硬核 KPI 红线 | `Cloud利润率≥25%, Search增速≥8%` |
| `宏观分%` | 中观三周期得分率（%） | `56` |
| `质量分%` | 企业稳态质量分率（#5–24 项，≥75% 自动进皇冠池） | `73` |
| `时机分%` | 价格时机分率（#1–4, #25–30 项，≥75% 绝佳击球区） | `55` |
