# 📈 股票池（85% 皇冠复利 × 15% 新物种奇兵 · 双池杠铃看板）

> [!info] 组合顶层架构：巴菲特 × 泰尔「85 / 15 杠铃策略」
> 页面由 `03_个股研究与股票池/` 下所有活跃标的笔记自动汇总而成，实行严格的**双池分轨管理**与**「🟢学徒买 + 🔴师傅卖」双扳机监控**：
> 1. **💎 皇冠明珠·稳态复利池（85%–90% 资金上限）**：用 [[选股评分模型]]（30维度）与 [[加密资产评分模型]]（21维度）考核，只选 `quality_score >= 70%` 的顶级现金牛/硬通货，等错杀折价按 3-4-3 扣动买点扳机。
> 2. **🚀 新物种·颠覆者观察池（10%–15% 资金上限）**：用 [[颠覆性新物种与生命力评估模型]]（15维度第一性原理记分卡）考核，专门捕捉像 [[SpaceX SPCX]] 这样早期因高研发/高 CapEx 导致传统财务表失真、但具备 **10倍成本下降曲线（莱特定律）与极客创始人统治力** 的时代级新物种（`vitality_score >= 65%`）。

## 🚀 二、新物种·颠覆者观察池（新物种生命力 ≥ 65% · 10~15% 奇兵高赔率仓）

> [!tip] 为什么单独设立新物种池？（详见 [[颠覆性新物种与生命力评估模型]] & [[新物种与候选猎物雷达池]]）

## 📋 五、YAML 属性填写字典（新增标的必读）

| 属性 | 填什么 | 示例 |
| :--- | :--- | :--- |
| `ticker` | 股票/代币代码 | `GOOGL` / `BTC` / `SPCX` |
| `company` | 公司/资产名称 | `Alphabet Inc.` |
| `asset_type` | `股票` 或 `加密资产` | `股票` |
| `pool_type` | `💎皇冠明珠复利池`、`🚀新物种观察池`、`⏳周期观察池` 或 `🧬0→1研发VC池(≤2%)` | `💎皇冠明珠复利池` |
| `macro_bucket` | `🌊流动性久期` / `🔥通胀实物` / `🛡️刚需现金牛`（单篮子 ≤50%） | `🌊流动性久期` |
| `sector` | 行业/赛道 | `互联网 / 云计算 / AI` |
| `status` | `观察中` / `已建仓` / `已放弃`（标为已放弃将自动从云端日报隐藏） | `观察中` |
| `price` | 当前价格 | `285` |
| `target_buy_price` | **🟢 学徒买点**：预设 30% 底仓狙击价或右侧拐点条件 | `$230 或单季FCF转正(+$150亿)` |
| `target_sell_price`| **🔴 师傅卖点**：泡沫止盈价 / 移动护利线 / 逻辑证伪清仓红线 | `$420(PE>35x泡沫止盈) 或 Cloud利润率<20%证伪清仓` |
| `target_position_pct` | **计划目标仓位**（%） | `15` |
| `position_pct` | 当前实际持仓占比（%） | `0` |
| `next_risk_date` | **💣 下次排雷日历**（解禁 / 财报 / 诉讼） | `2026-12-08` |
| `macro_score` | 中观三周期得分率（%） | `56` |
| `quality_score` | 企业稳态质量分率（#5–24 项，≥70% 自动进皇冠池） | `73` |
| `timing_score` | 价格时机分率（#1–4, #25–30 项） | `55` |
| `vitality_score` | **新物种生命力得分率（%）**（按 15 维度新物种模型，≥65% 自动进新物种池） | `85`（稳态股填 `0` 或留空） |
| `score_rate` | 微观综合得分率（%） | `68` |
| `traps_hit` | 17 项陷阱命中数 | `2` |
| `verdict` | 一句话结论 | `头号候选，等 CapEx 拐点或回调` |
