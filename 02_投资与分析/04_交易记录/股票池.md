## 💎 皇冠明珠·等跌狙击池（企业质量分 ≥ 70%）

> [!tip] 为什么单独置顶这个池子？
> 把**「顶级商业模式（高企业质量分）」**与**「当下价格/周期卡点（时机分）」**拆开！这里躺着的是真正具备宽护城河的皇冠明珠（如 [[Alphabet GOOGL]]、[[Bitcoin BTC]]），普段太贵或处于行业 CapEx 狂潮期不买，但预先设好 **`狙击买点（target_buy_price）`**，一旦市场恐慌错杀或周期拐点出现，立刻按 3-4-3 纪律扣扳机！

## 📋 使用时填哪些属性

| 属性               | 填什么                                             | 示例                          |
| :--------------- | :---------------------------------------------- | :-------------------------- |
| `ticker`         | 股票/代币代码                                         | `GOOGL` / `BTC`             |
| `company`        | 公司/资产名称                                         | `Alphabet Inc.`             |
| `asset_type`     | `股票` 或 `加密资产`                                   | `股票`                        |
| `macro_bucket`   | `🌊流动性久期` / `🔥通胀实物` / `🛡️刚需现金牛`（单篮子持仓 ≤50%） | `🌊流动性久期`                   |
| `sector`         | 行业/赛道                                           | `互联网 / 云计算 / AI`            |
| `status`         | 观察中 / 研究中 / 已建仓 / 已放弃                           | `观察中`                       |
| `price`          | 当前价格                                            | `286`                       |
| `target_buy_price` | 预设狙击买点或右侧触发条件                                   | `$230 或单季FCF转正`            |
| `macro_score`    | 中观三周期得分率（%）                                     | `56`                        |
| `quality_score`  | 企业质量分率（#5–24 项，≥70% 自动进皇冠池）                     | `74`                        |
| `score_rate`     | 微观综合得分率（%）                                      | `68`                        |
| `traps_hit`      | 17 项陷阱命中数                                       | `2`                         |
| `position_pct`   | 实际目标仓位（%）                                       | `0`                         |
| `verdict`        | 一句话结论                                           | `头号候选，等 CapEx 拐点或回调` |

> [!tip] 视图不会自动更新属性
> 打分完成后需要手动把结论填回 YAML，否则视图里对应列会是空的。
> 个股笔记和交易记录共用一个文件夹，靠 `action` 属性区分：**个股分析不填 `action`，交易记录必须填**。
