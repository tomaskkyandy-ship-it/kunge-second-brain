# 📓 投资决策日志

> [!abstract] 为什么这是最重要的文件
> 你抄的 101 条清单里排第 10 的铁律是「做投资决策时记录决策日记」，但库里一直没有对应文件。
> **没有日志，你永远分不清「决策对了」和「运气好」** —— 这正好是 [[结果论陷阱]] 的核心。
>
> 记录放在 `04_交易记录/` 下，和个股分析同目录，靠 YAML 的 `action` 属性区分，视图会自动分流。

## 📝 怎么记一笔

1. 复制 [[_交易记录模板]] 到本目录
2. 重命名为 `YYYY-MM-DD 公司名 买入.md`
3. **交易前**先填「决策依据」+「EV 估算」+「风险控制」——这是防自我欺骗的关键
4. 回填顶部 YAML 属性
5. 卖出时补填「卖出记录」+「归因复盘」

| 属性 | 填什么 | 示例 |
| :--- | :--- | :--- |
| `ticker` | 股票代码 | `600519.SH` |
| `company` | 公司名称 | `贵州茅台` |
| `action` | 买入 / 加仓 / 减仓 / 卖出 | `买入` |
| `trade_date` | 日期（YYYY-MM-DD） | `2026-11-06` |
| `price` | 成交价 | `1680` |
| `shares` | 股数 | `100` |
| `amount` | 金额 | `168000` |
| `position_pct` | 占组合比例（%） | `8` |
| `ev_estimate` | 预期 EV（%） | `18` |
| `max_loss_pct` | 可承受亏损（%） | `25` |
| `outcome` | 进行中 / 盈利 / 亏损 / 持平 | `进行中` |

## 🎯 记录纪律

> [!important] 三条铁律
> 1. **交易前写**：必须在成交前填好 EV 估算和核心假设，事后补写等于没有记录
> 2. **假设必须可证伪**：「管理层优秀」不算，「未来 3 年 ROE ≥ 20%」才算
> 3. **诚实归因**：结果是运气还是能力，只有如实记下才能区分

### 归因四象限（对应 [[结果论陷阱]]）

| 决策 | 结果 | 含义 | 该怎么做 |
| :---: | :---: | :--- | :--- |
| ✅ 对 | ✅ 好 | 应得的（skill） | 继续复刻 |
| ✅ 对 | ❌ 差 | **运气不佳** | **不要怀疑体系** |
| ❌ 错 | ✅ 好 | **定时炸弹** | **必须修正** |
| ❌ 错 | ❌ 差 | 学费 | 记录教训 |
